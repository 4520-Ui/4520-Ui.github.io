# Leo 的奇想小屋 · 创意方向

更新：2026-10-24。阶段：本地版本已实现，进行最终发布验收。

## 最新调整

用户明确：不需要将场景与专业方向匹配，希望更多专业之外的创造元素，首先满足自己看着有意思。采用“奇想小屋”作为页面名称。原先的工作室是空间起点，幻想内容可以自由发展；不将所有物件解释为职业符号。

主视觉加入云鲸、行星盆栽和通往另一片海的小门，移除电路操作与工程屏幕。角色放松涂鸦。首页优先呈现漫游签、手记、生活，项目保留在后面的“折腾小物”和直接导航中。保留内容真实性，但插画可以表现明确的幻想。

新增轻量漫游签：一次点击换一个小想象提示，不收集信息，也不要求访客完成任务。台灯与纸飞机是可选彩蛋，所有内容直接可读。

## 已确认的偏好

- 手绘动漫工作室、个人角色、温暖而有趣。
- 插画、构图、转场可以大胆；操作直接简单。
- 个人主页、作品集、知识分享、成长记录仍是网站的核心内容。
- 参考 Nomadic Tribe 的梦境氛围、漫画质感与章节叙事。设计原创场景，不复用其角色、素材或品牌。
- 功能继续采用 Astro 静态网站、Obsidian 精选内容单向发布与 GitHub Pages。

## 核心概念

**一间向想象世界敞开的工作室。**

访客来到一座漂浮的小岛。岛上有 Leo 的房间：桌面上是电路与草稿，书架上是持续生长的知识，窗外是还在探索的生活。现实中的兴趣成为场景中的物件，让视觉与本人产生联系。

首页标题：**欢迎来到，Leo 的奇想小屋。**

副标题：你好，我是 Leo · 吴鸿钰。这里装着一些想法、走过的路，和暂时没想明白的事。

贯穿全页的视觉线索：桌上的电路线 → 书页里的批注线 → 窗外的小路 → 寄出的信。线条随章节改变用途，将技术、学习与生活串成一个故事。

命名为提案，可继续调整。不要写成虚构个人经历。

## 插画与版式

- 纸张米白为底，墨蓝线条，雾蓝远景，鼠尾草绿植物，少量珊瑚橙强调。
- 铅笔线与轻水粉质感，轮廓稍有手绘变化，保留留白；文字使用清晰的现代中文字体。
- 首页使用大画幅、非对称构图和章节之间的视觉联系。每段有自身的构图，不重复同一种卡片网格。
- 角色身份沿用现有头像识别点；最终画风需与场景统一。已有多个角色方向，暂不替用户宣布最终选择。
- 首屏已接入原创幻想插画 `src/assets/studio/studio-dream.png`；上一版工作室插画保留为设计历史，当前页面不加载。
- 文章保持约 720px 的正文宽度，插画只在页头或页边提供气氛，不覆盖文字。

## 轻量互动

1. 鼠标移动时前景与远景轻微错动；只在精细指针设备开启。
2. 台灯点击切换暖光，局部变化；明确按钮名称与状态。
3. 点击芯片或书本可直接到作品或记录；提供可见文字标签，不要求访客猜热点。
4. 向下滚动自然进入下一章，使用轻微场景位移和纸页过渡；不接管滚轮，不强制等待。
5. 纸飞机作为可选的一次性小彩蛋；不阻碍获取邮箱或页面跳转。

第一版包含暖光、纸飞机和漫游签三项可选互动。声音默认关闭；若以后加入，需要明确的用户控制。

## 页面映射与移动端

- 五个导航保留：首页、作品集、记录、关于我、联系我。
- 场景是内容的另一种入口；普通导航、文字链接、浏览器返回和直接地址访问均有效。
- 手机使用重新构图的竖向插画与单列章节；将物件入口变成触摸友好的文字按钮。
- 小屏不缩小整张桌面世界来塞入全部内容，不要求拖拽或滑动画布。
- 遵循系统减少动态效果的设置；信息、按钮和文章在动画关闭时保持完整。

## 实施顺序

1. 完成原创主视觉与首屏构图，展示明确的视觉方向。
2. 将首页改成连续的章节叙事，验证桌面与手机的构图。
3. 延展作品、记录、关于与联系页面的视觉语言，保持阅读体验。
4. 验证导航、内容链接、动效偏好、图片加载与移动端。
5. 在保留已完成的 Obsidian 发布机制和内容校验的基础上，构建并部署通过验收的网站。
